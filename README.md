# Profanity Cleaner
An AI desktop and web app for modifying audio files, censoring profanity and toxic talks with custom options and more.

### Pre-trained Model
Download the toxicity model [toxicity_model.keras](https://github.com/engmohammedsobhy/profanity-cleaner/releases/download/v1.0.0/toxicity_model.keras) and place it directly in the root directory alongside `toxicity_detoxifier.py`.
